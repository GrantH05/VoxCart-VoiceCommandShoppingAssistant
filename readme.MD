# VoxCart - Voice Shopping Assistant

VoxCart is a **Python + Streamlit voice-based shopping assistant** that allows users to manage shopping lists and search for products using natural-language voice or text commands.

## Features

* Voice and text commands
* Add, remove, and update shopping-list items
* Quantity and unit detection
* Automatic product categorization
* English, Hindi, Spanish, and French voice input
* Product search with brand and price filters
* Smart, seasonal, and sale recommendations
* Product substitutes
* SQLite shopping history
* Responsive Streamlit interface

## Tech Stack

**Python | Streamlit | SQLite | Streamlit Mic Recorder**

## Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

Open:

```text
http://localhost:8501
```

## Example Commands

```text
Add milk
Add 2 bottles of water
Remove milk from my list
Change milk quantity to 3
Find organic apples
Find toothpaste under $5
```
